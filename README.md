## 🕹️ Project Overview
**ArcadeFlow 2D** is an open-source, distraction-free digital illustration and frame-by-frame 2D animation software. It combines the tactile, gesture-driven ergonomics of **Procreate** with the high-speed muscle-memory of **gaming radial weapon wheels** and the vivid aesthetics of **Y2K retro-arcade neo-brutalism**.

---

## ⚡ Core Innovations & Features

### 1. 🎯 Gaming-Style Radial HUD (Prototype Inspired)
- **Zero Canvas Obstruction:** 100% full-bleed canvas with zero permanent toolbars.
- **On-Demand Polar Bloom:** Triggered by holding `Spacebar` or tapping the stylus button.
- **Directional Flick Selection:** 8 equidistant tool sectors (*Pencil, Ink, Eraser, Color, Timeline, Smudge, Paint, Charcoal*) with a center deadzone and dynamic status telemetry.

### 2. 🎞️ Frame-by-Frame 2D Animation Dock
- Collapsible bottom timeline with play/pause looping, FPS control (6, 12, 24 FPS), frame duplication, and ghosted **onion-skinning**.

### 3. 🎨 Y2K Retro-Arcade Design System
- **Customizable Neon Glow Tokens:** User-selectable accent glows (*Cyber Pink, Electric Teal, Arcade Gold, Acid Lime, Vapor Violet*).
- **Dual-Typography Switcher:** Instant one-click toggle between **Helvetica (Swiss Clean)** and **8-Bit Arcade Pixel font**.

## 🚀 Running the Interactive Prototype

Simply open `index.html` in any modern web browser:
```powershell
Start-Process "index.html"
```

- **Hold Spacebar** anywhere on the canvas to summon the Radial HUD.
- **Click the Font toggle** in the top bar to switch between Helvetica and 8-bit Pixel font.
- **Click "THEME"** to customize accent glows and color palettes.
- **Switch to ANIMATION mode** to use the multi-frame timeline and onion-skinning!
